#1 Instrucción nivel 1 ( Orden simple )

Escribe un texto para promocionar la venta de café

#2 Instrucción nivel 2 ( Especifíca el producto )

Escribe un texto promocional para vender un nuevo café artesanal de origen colombiano con notas de cata a chocolate y avellana

#3 Instrucción nivel 3 ( Define público y tono )

Escribe un texto promocional para un café artesanal colombiano con notas de chocolate, el cual está dirigido a jovenes (25-35 años) utilizando un tono cercano y moderno.

#4 Instrucción nivel 4 ( Asignación de rol )

Actúa como un Copywriter experto en marcas de estilo de vida. Escribe un texto promocional para un café nuevo artesanal colombiano, enfocado en jóvenes, con un tono cercano y moderno.

#5 Instrucción nivel 5 ( Inclusión de contexto de negocio y objetivo)

Actúa como Copywriter experto. Nuestra cafetería " Café Inetum" Lanzará una edición limitada de grano colombiano disponible solo en la tienda online. Nuestro objetivo es generar urgencia y impulsar las ventas en los primeros dias. Escribe el texto para una publicación en Instagram.

#6 Instrucción nivel 6 ( Adición de restricciones y exclusiones )

Actúa como Copywriter experto. Escribe una publicación en Instagram para el lanzamiento web del café limitado de "Café Inetum".
Limitate a 80 palabras, incluye un llamado a la acción directo a la web y evita publicidad común como " el mejor café del mundo " o " sabor incomparable ".

#7 Instrucción nivel 7 ( Guiado de razonamiento previo )

Actúa como Estratega de contenidos. Antes de empezar, identifica en 2 puntos breves la principal motivación de compra de un profesional que teletrabaja. Luego, redacta el copy promocional para nuestro café conectando con esas motivaciones.

#8 Instrucción nivel 8 ( Few-Shot Prompting )

Actúa como Copywriter. Redacta nuestra campaña del café colombiano siguiendo la estructura de este ejemplo:
-[Gancho] ¿Tu café de la mañana sabe a rutina?
-[Cuerpo]: Cambia tus mañanas con granos tostados en lotes pequeños.
-[CTA]: Pide el tuyo antes de que se agote.

#9 Instrucción nivel 9 ( Control de estructura de salida )

Actúa como Copywriter Senior: Redacta la campaña para el café colombiano de " Café Inetum " y organiza la respuesta exactamente en este formato:

Titular principal ( Maximo 8 palabras )
Cuerpo ( Entre 50-80 palabras )
CTA ( 1 frase directa )

#10 Instrucción nivel 10 ( Prompt avanzado con rol + contexto + Tarea + Restricciones + Esquema de salida )

Rol : Eres el director de estrategia digital que se especializa en e-commerce gastronomico.

Contexto : La marca " Café Inetum " lanza 100 bolsas numeradas de un lote de café colombiano. Queremos agotar el inventario en 48 horas mediante las redes sociales.

Instrucciones :

Analiza brevemente el perfil del comprador ideal ( 1 oración )
Diseña la propuesta de contenido promocional según la tabla solicitada.

Restricciones :

Tono: Moderno y conciso.
Exclusiones : Prohibido usar palabras como " delicioso " o " increíble ".
Extensión máxima del texto redactado : 120 palabras.

Formato de salida :

La propuesta debe seguir el siguiente orden :

[ Elemento del post ] -> [ Contenido redactado ] -> [ Justificación estratégica ].

Incluir filas específicas para :

1- Gancho de apertura
2- Origen de lote
3- Disparador de urgencia ( limitar lote )
4- Llamado a la acción
